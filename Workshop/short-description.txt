Research, build and run a data center: networked server racks, cooling, UPS units and an operations console that produce data cartridges to sell. Upgrade tree, security doors, cartridge specialization, drifting market prices, an occasional espionage raid, timed data contracts for a silver bonus, and Meridian, an AI core with a personality that runs the place and slowly develops a trait of its own. Vanilla-friendly: no DLC, no Harmony.
